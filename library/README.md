# 本地书库

把你自己合法拥有的书籍文件放进这个目录，然后在网页的「本地」页点击刷新。

支持格式：

- `.txt`
- `.md` / `.markdown`
- `.epub`
- `.pdf`（在系统 PDF 查看器中打开，不能下载到网页离线缓存）

子目录会递归扫描。TXT/Markdown 会按「第一章」「Chapter 1」等标题自动分章；EPUB 会读取书脊顺序、目录标题和封面。

## 隐私与版权

- 这个目录中的文件只在本机使用，不会上传到服务器，也不会提交到 Git。
- 请只放你合法拥有的文件，或公共领域/开放许可内容。
- 不要在公开仓库中存放受版权保护的小说、漫画、扫描书或盗版资源。

## 添加文件

```text
library/
  我的书/
    某本小说.txt
    某本小说.epub
```

刷新后，网页会显示书名、作者、章节和封面。手机端需要先点击「下载到手机」，才能在断网时阅读。
