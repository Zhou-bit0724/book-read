# 公共领域与开放获取资源

本项目不附带受版权保护的小说、漫画或扫描书。这里只维护一份合法来源清单，方便你自己下载后放入 `library/`。

- `catalog.json`：来源、内容类型、常见格式和许可提示。
- `samples/`：可以随项目提交的公共领域示例。

使用前请逐项确认许可。Project Gutenberg、Standard Ebooks、青空文库等来源的作品权利状态可能因国家和版本而异；“可免费阅读”不一定等于“可以再分发”。

推荐流程：

1. 从来源页面下载 TXT 或 EPUB。
2. 确认作品和译本/校注的许可。
3. 放入项目根目录的 `library/`，必要时重命名为 `书名 - 作者.ext`。
4. 在网页「本地」页刷新，再下载到手机离线阅读。

不要把从商业网站抓取的小说、漫画、扫描 PDF 或未授权译本加入本目录或提交到公开仓库。
